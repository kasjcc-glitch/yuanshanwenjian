使用方法

1. HTML 结构：每个帖子中，评论区域用 <div class="comment-box"> 包裹，紧接在 <button class="comment-toggle"> 按钮的下方。

2. 按钮绑定：按钮添加 onclick="toggleComments(this)" 属性即可。

3. JS 引入：将下方 JavaScript 代码复制到页面底部，或单独保存为 comments.js 后用 <script src="comments.js"></script> 引入。

4. CSS 引入：将 .comment-toggle 和 .comment-box 相关的样式复制到你的样式表中。

5. 评论数自动更新：按钮文字格式为 [ 展开 N 条评论 ] 或 [ 收起 N 条评论 ]，JS 会自动替换"展开"/"收起"关键词。
